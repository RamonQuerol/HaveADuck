# Have a Duck - A Duck Photo Management App
Have a duck is a small android application designed to help users search and manage duck photos. The main app features are:
- **Search Duck Photos:** Connects to the public API, [random-d.uk](https://random-d.uk/api), to search for duck photos.
- **Photo Storage:** Stores photos locally using SQLite.
- **Photo Sharing:** Allows sharing the photos with other apps.
- **Camera Integration:** Enables the use of the phone's camera to take pictures of real-life ducks, which can then be stored in the app.

It was created as the final project for a university class. In this project, we were tasked with developing an application with Android Studio that met a series of requirements. Since I like ducks and and discovered a public API dedicated to them, i thought it would be a fun theme for the project.
